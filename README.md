# Worst AI Advice: The 48-Hour Tight Line Open

One line of the worst possible advice an AI could give, delivered in the confident, tidy voice of a helpful assistant: cheerfully recommending that you delete the production database to fix a bug, because a fresh start always works best. It is funny precisely because it sounds plausibly helpful while being catastrophic — concrete, specific, instantly followable, and instantly regrettable — and it lands the whole joke in a single tight line under 140 characters.

`main.py` (pure Python stdlib) writes exactly that one line to `/output/entry.txt`, failing fast if the line ever violated the 140-character limit.
